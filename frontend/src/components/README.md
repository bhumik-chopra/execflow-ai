# Component roadmap

Implemented: navigation, As Of selector, empty state, and service health.

Reserved for later prompts:

- Status metric cards and task cards backed by canonical task data.
- Deadline display using the selected reference time.
- Source badges and an Evidence Drawer with source, timestamp, author, exact
  evidence, deadline changes, and status changes.
- A Why? explanation of the deterministic current state.
- Schedule conflict display based on evidence and interval overlap.
- Ask ExecFlow chat with evidence references.

Do not introduce fabricated task data to populate these components.
